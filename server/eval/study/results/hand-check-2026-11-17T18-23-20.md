## t002 · Unable to open PDF files
> Good morning, when I click on a PDF attachment in my email, nothing seems to happen and no program opens the file. I would appreciate some help opening these documents when you have a moment. Thank you.

**Hidden cause:** No working default app is set for PDF files.  
**What fixes it:** Choose Open with and pick Edge (or Acrobat Reader), and set it as the default app for .pdf files.

1. **Save the PDF to your desktop, then double-click it**: Right-click the PDF attachment in your email and choose Save or Download. Then double-click the saved file to see if it opens.
2. **Drag the PDF into your web browser**: Open Chrome, Edge, or another web browser and drag the saved PDF file into the open window. Most browsers can display PDFs without any extra program.
3. **Choose a PDF program to open the file**: Right-click the saved PDF, select Open with, and pick Edge, Acrobat, or another PDF reader. Tick the option to always use that program if it is offered.
4. **Install any pending Windows or app updates**: Open Settings and go to Windows Update, then select Check for updates and install anything listed. Restart the computer afterward if asked.
5. **Restart your computer**: Save your open work, then restart the computer. After it starts again, try opening the PDF attachment from your email once more.

4. **Adjust the scale for the second monitor**: In the same Display settings, select the new monitor and change the Scale setting, such as from 100% to 125%, until the text looks a comfortable size. Keep the scale the same on both screens if you'd like them to match.
5. **Restart the laptop**: Save your work, then restart the laptop so it refreshes the display settings for the new monitor. Check the text size again once it has started up.
