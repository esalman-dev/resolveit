## t002 · Unable to open PDF file
> Good morning, when I click on a PDF attachment in my email, a window pops up asking me to choose how to open the file. I am not sure which program I should pick, and I would appreciate some help getting the files to open properly. Thank you for your time.

**Hidden cause:** No working default app is set for PDF files.  
**What fixes it:** Choose Open with and pick Edge (or Acrobat Reader), and set it as the default app for .pdf files.

1. **Open the attachment with a PDF reader you already have**: Save the PDF to your Desktop or Downloads folder first. Right-click the file, choose Open with, and pick Microsoft Edge or Adobe Acrobat Reader if you see either one in the list.
2. **Set a default PDF program**: Open Settings, go to Apps, then Default apps, and search for .pdf. Choose Microsoft Edge or Adobe Acrobat Reader so PDFs open in that program from now on.
3. **Check for app updates**: If you use Adobe Acrobat Reader or another PDF program, open its Help or Settings menu and check for updates. Install any available updates, then try the attachment again.
4. **Restart your computer**: Save your open work, restart the computer, and then try opening the PDF again. A restart can clear problems with programs that are stuck.
